Robo·Boy

ROS 2 · web · desktop · mobile

your ROS 2 robot workspace.

Drive, see and command robots from one tab: pads, a 3D view with TF, cameras, behavior trees, an AI assistant, time series and recordings, arranged the way you work. It runs in the browser, on the desktop, on iOS and Android, and it grows with panels you build yourself.

02 — About

built on the side. made to be useful.

tessel·la is an independent robotics project for students, hobbyists, and engineers. The goal is simple: software that feels friendly, useful, and easy to take apart.

  • Open by default

    The code lives on GitHub. Fork it, break it, send it back better.

  • Small and focused

    One useful, well-made tool beats ten that gather dust.

  • Friendly to humans

    Robots are weird. The software you use to talk to them shouldn't be.

tessel·la started with a simple idea: a robot controller could feel like a toy and still work like a serious tool. Something worth pulling out at a demo, not another dashboard hidden behind a VPN.

Robo·Boy is the first project. The code is open, and feedback is welcome.
